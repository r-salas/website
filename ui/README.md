# UI - rubensalas.ai

React + Vite + TypeScript frontend, styled with Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

The dev server proxies `/public` requests to `http://localhost:8000` (the API).

## Scripts

- `npm run dev` – start dev server
- `npm run build` – type-check and build for production
- `npm run preview` – preview the production build
- `npm run lint` – run ESLint
